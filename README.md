# Sofía

Tomas, pañales, sueño, turnos y vacunas de la bebé, en un solo lugar y a un toque.

## Puesta en marcha

1. Crear un proyecto en [Supabase](https://supabase.com) y correr `supabase/migrations/0001_init.sql` en el SQL Editor.
2. Copiar `.env.example` a `.env.local` y completar URL y publishable key (Project Settings → API).
3. `npm install` y `npm run dev` → http://localhost:3000
4. Crear la cuenta, completar la ficha. Desde Ficha → Ajustes se invita a la otra persona por email.

En el celular: abrir la URL y "Agregar a pantalla de inicio".
